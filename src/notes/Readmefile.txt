📝 Notes Management System
Description

The Notes Management System is a simple REST API that allows users to create, read, update, and delete personal notes. Each note contains a title, description, and timestamps. This project is ideal for learning the fundamentals of NestJS, including modules, controllers, services, DTOs, validation, and basic Supabase integration.

Main Features
Create a new note
View all notes
View a single note by ID
Update an existing note
Delete a note
Automatically store creation and update timestamps
