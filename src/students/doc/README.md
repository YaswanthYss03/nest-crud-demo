# Students Module Production Worklog

This directory records the production-hardening work for the `students` module.

## Working rules

- Complete one implementation step at a time.
- Do not begin the next step until the current step is tested.
- Record the completed change, design decisions, validation commands, and remaining risks in a new Markdown file.
- Keep all environment-specific values outside source control.
- Treat performance claims as measured results, not assumptions.
