✅ Todo Manager
Description

The Todo Manager helps users organize their daily tasks. Users can create tasks, assign priorities, set due dates, track completion status, and update or remove tasks. This project introduces filtering, sorting, and query parameters while reinforcing CRUD operations.

Main Features
Create new tasks
Update task details
Mark tasks as completed or pending
Assign priorities (Low, Medium, High)
Set due dates
Delete tasks
View all tasks or a specific task
